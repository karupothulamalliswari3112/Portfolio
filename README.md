## 🚀 Run Locally

```bash
git clone https://github.com/karupothulamalliswari3112/Portfolio.git
cd Portfolio
```

Open `index.html` in your browser. No build step is needed.

## 🌍 Deploy on GitHub Pages

1. Push the files to the `main` branch.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
