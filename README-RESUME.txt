# Resume Placeholder

This is a placeholder for your actual resume file.

## What to do:
1. Replace this file with your actual resume PDF.
2. Name it exactly `resume.pdf` (case-sensitive).
3. Place it in the same folder as `index.html` (the project root).

The "Download Resume" button in the hero section is already linked to `/resume.pdf`,
so once you add your real PDF file here, the button will download it automatically.

Do NOT commit your real resume to a public git repository if it contains sensitive
information like your phone number or full address.
